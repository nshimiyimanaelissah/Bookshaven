How to read effectively

Set a goal for each reading session. Preview the chapter, ask questions, then read actively. Summarize in your own words after every section — this simple step doubles retention.

  • Read 25 minutes, rest 5
  • Highlight key ideas only
  • Write a 3-line summary

Memory techniques

Spaced repetition beats cramming every time. Review notes after 1 day, 1 week, and 1 month. Use flashcards for definitions and concept maps for structure.

  • Review after 1 day, 7 days, 30 days
  • Use concept maps for structure
  • Teach the idea to someone else

Note-taking method

The Cornell method: divide the page into notes, cues, and summary. Write notes during reading, cues after, and a summary at the end. It forces you to process the material twice.

  • Right column: main notes
  • Left column: cues & questions
  • Bottom: 5-line summary

Learn across languages

Read the same passage in two languages. Start in the language you know best, then read the translation. Compare sentence structures to build vocabulary naturally.

  • Read EN → then RW or FR
  • Compare 3 sentences per page
  • Keep a bilingual glossary

Build a reading habit

Attach reading to an existing habit: after coffee, before bed, on the commute. Small consistent sessions (15 minutes daily) beat long irregular ones.

  • Same time, same place
  • Start with 15 minutes/day
  • Track your streak

Active reading

Interact with the text: underline, question, connect to what you already know. Passive reading is forgettable; active reading is permanent.

  • Question what you read
  • Connect to prior knowledge
  • Predict before reading on
